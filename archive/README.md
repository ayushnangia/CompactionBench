# Archive

This folder holds older context that should not be treated as the current project story.

Archived files include:

- old sprint notes,
- exploratory research plans,
- superseded HTML reports,
- Slack-ready drafts,
- one-off work logs,
- unrelated handoff notes.

The archive is not deleted because some details are still useful for tracing how experiments evolved. For current claims, use:

- `CONSOLIDATED.md`
- `RESULTS.md`
- `docs/README.md`
- files under `docs/current/`
