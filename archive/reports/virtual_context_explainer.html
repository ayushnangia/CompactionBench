Virtual Context Memory

An OS-like memory system for long-context agents: the model does not search or page manually. The system loads the right evidence before the model answers.

hidden page tablesystem-managed retrievalresident evidence packet0 model tools

The simple idea

Virtual context means: keep the full source outside the model, split it into pages, let the system choose the useful pages, and give the model only the current evidence packet.

The model should not think: “Which page should I search?” The model should only think: “Given this evidence, what is the answer?”

Why this is more OS-like

Operating systemVirtual context
Disk stores all data.Original long source is stored outside the model.
RAM holds only the current working set.Prompt holds only the evidence packet.
Page table maps page IDs to locations.Hidden index maps source pages to files/line ranges/previews.
Kernel loads pages.Memory kernel retrieves evidence before the model call.
Program does not manually load pages.Model does not call pager.py or grep.

Concrete example

Bad retrieval trap

The long source may contain unrelated carrier prose:

Mary Linden went to Didlum's shop.

If the model greps “Mary”, it may answer about the wrong Mary.

Virtual context fix

The memory kernel extracts concise benchmark facts:

Mary journeyed to the bathroom.

The model receives the relevant event trace, not all noisy Mary mentions.

What the model actually receives

You are answering from TRANSPARENT VIRTUAL CONTEXT.
A system memory kernel has already retrieved the relevant source pages and evidence.
Do not search files or use tools.

<VIRTUAL_CONTEXT_EVIDENCE>
Evidence 1: BABILong concise event trace
[001] John travelled to the hallway.
[002] Mary journeyed to the bathroom.
</VIRTUAL_CONTEXT_EVIDENCE>

Question: Where is Mary?

The model never sees the full page system. It only sees the resident evidence.

What is still missing

Page-fault retry

Future version should verify if the answer is supported. If not, the system loads more pages and asks again.

Aggregation operators

OOLONG needs roll/spell tables, counting, percentages, first/last extraction. Retrieval alone is not enough.

One-line summary

Virtual context is like giving the model RAM, not the disk: the full source stays outside, the system loads the current working set, and the model answers from that evidence without doing memory management itself.
