# How people use LLMs — Real datasets on HuggingFace

## Verified HF datasets (checked May 2025)

### Coding agents
| Dataset | Link | Relevance |
|---|---|---|
| SWE-chat | https://huggingface.co/datasets/SALT-NLP/SWE-chat | 6k real Codex sessions, 63k prompts |
| SWE-bench | https://huggingface.co/datasets/princeton-nlp/SWE-bench | 2,294 real GitHub issues |

| Dataset | Link | Relevance |
|---|---|---|
| BABILong | https://huggingface.co/datasets/RMT-team/babilong | 20 reasoning tasks, up to 10M tokens |
| OOLONG-synth | https://huggingface.co/datasets/oolongbench/oolong-synth | Aggregation over long context |
| OOLONG-real | https://huggingface.co/datasets/oolongbench/oolong-real | Real D&D transcript reasoning |
| LongMemEval | https://huggingface.co/datasets/xiaowu0162/LongMemEval | Long-term chat memory |
| LongBench | https://huggingface.co/datasets/THUDM/LongBench | 21 datasets, bilingual |
| RULER | https://huggingface.co/datasets/simonjegou/ruler | Multi-needle retrieval |
