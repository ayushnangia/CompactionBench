Conclusion

RLM depth-0 is a real new arm and it changes the picture: on strict scoring it beat grep and the current virtual-context variants overall, mainly because it was much better on BABILong exact memory retrieval.

But it is not the final answer: it was slower, its relaxed score was below virtual context, and it underperformed on OOLONG. The next meaningful RLM test is rlm_repl_depth1, where code can ask sub-LLMs to label chunks and then aggregate the results.
