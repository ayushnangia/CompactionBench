Cohort Studies
20 instances. Each instance is a SQLite database of patient records. The agent runs SQL queries and survival analysis to find treatment effects.
Patient DB (SQLite)
→

→
Tool executes query
→
Results returned
→
Agent reports findings

What the agent receives:

HERALD Study — Suburban Region — 192 patients
Database: herald_suburban.db

Available tables: patients, treatments, outcomes, visits
patient_id age sex treatment_start treatment outcome outcome_time
P001 62 F 2023-01-15 drug_a alive 730 days
P002 58 M 2023-02-01 placebo deceased 180 days
P003 71 F 2023-01-20 drug_b alive 540 days
...
Agent tools run_query(sql) · kaplan_meier(cohort) · log_rank_test(groups) · define_cohort(criteria)

Typical session
1. SELECT COUNT(*), treatment, outcome FROM patients GROUP BY treatment, outcome
2. "drug_a shows lower mortality. Let me check with Kaplan-Meier."
3. kaplan_meier(cohort=[patients on drug_a]) → survival curve
4. "3 more instances remain. I should check if drug_b performs similarly in the next study."

Scoring Agent reports findings for pre-defined cohorts. Evaluated on accuracy of survival group assignments and p-value correctness.
Why text-only scoring fails: In the real CLB benchmark, the agent writes and runs code in a Docker container. It iterates — runs SQL, sees results, adjusts. In our text-only CompactionBench version, we strip all of that and ask the model to answer from static context. The model gives a text explanation ("drug_a appears effective") but the gold expects structured output (SQL + p-values + CSV). Format mismatch, not model failure.
