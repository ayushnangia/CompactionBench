TL;DR

Main answer

Do not say “grep always beats full context.”

Strict exact scoring made file search look better in the clean control, but normalized/semantic scoring shows a more nuanced picture.

The real takeaway is: keep original sources searchable and also give the model enough context to reason.

Most important caveat

There are three different settings:

1. non-compacted full prompt

2. searchable source file

3. long agent chat with compaction

Do not mix these without labeling them.

RQ7 — What should we build next?

Answer: an infinite-context-like pager: keep original sources on disk, page in evidence as needed, and never treat lossy compaction as the source of truth.

Bad abstraction

“The agent remembers everything in the chat.” In long runs, old details get compacted or distorted.

Better abstraction

“The agent has a searchable memory filesystem.” It can load original pages when the current working context is not enough.
