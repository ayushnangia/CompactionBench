What changed from depth-0?

Depth-0

The root model writes Python over the external source. No sub-LM or child-RLM calls.

Depth-1 recursive

The root model still writes Python, but it must call a child RLM at least once using rlm_query-style helpers.

Verified recursion

After rerunning four violating rows, 250/250 tasks had at least one child RLM call. Total child calls: 658.

Simple names used below

Auto evidence search is the plain-English name for the code arm called virtual_context. It is like an automatic multi-file grep: the system searches/scans many chunks first, picks a small evidence packet, and gives only that evidence to the model.

Important: it is not literally the model running grep. The model used 0 tools in those rows; the harness did the evidence selection before the model answered.

Conclusion

Depth-1 recursion was implemented and verified, but it did not improve results. It was slower and less accurate than depth-0, grep, and auto evidence search on this fixed panel.

The likely reason is not that recursion is useless. It is that generic child RLM prompts are a poor fit for OOLONG’s event-counting semantics. OOLONG needs structured roll/spell operators or trained counting prompts, not unconstrained recursive summarization.
