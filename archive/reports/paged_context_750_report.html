Paged context experiment: 750 real-data runs

This report compares three ways for an agent to use a long source: direct full context, one searchable file, and paged external memory.

batch: artifacts/batches/real_paged_context_750/20260519-145809runs: 750strict + relaxed scoringreal BABILong + OOLONG

What we are testing

Full context

The whole source is pasted into the prompt. No search tools.

File search

The source is saved as full_context.txt. The agent can grep/search it.

Paged context

The source is split into page files. The agent searches a page table and loads pages as needed, like infinite context with paging.

How to read this

Good result for paging: paged context should match or beat file search on exact lookup, while doing better on broad reading/counting because pages preserve nearby context.

Bad result for paging: if it searches the wrong pages, it can confidently answer from irrelevant evidence. The examples above are the most useful part for improving the pager.
