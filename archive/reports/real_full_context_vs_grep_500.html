Full context vs file search

We ran the clean control people asked for: same real tasks, same model, no chat compression, comparing a direct full-context prompt against a searchable original file.

500 Codex runs 250 real tasks × 2 arms BABILong + OOLONG-real no synthetic tasks 0 run failures
TL;DR: file search won, but not by a landslide.

File search: 50 / 250 correct = 20%

Full context: 40 / 250 correct = 16%

Compaction status: this 500-run control had 0 compaction events. It is the non-compacted/lossless comparison.

So yes, on this real-data run, searchable source files did better overall than giving the model the whole source directly.

Important nuance

This does not mean “grep is always better.”

Full context still uniquely solved 15 tasks that grep missed. On OOLONG, exact accuracy tied.

What should we tell people?

Safe public claim

On 500 real-data runs, searchable source files slightly beat a direct full-context prompt overall.

The advantage was concentrated in BABILong exact-fact tasks.

For OOLONG-real aggregation tasks, exact accuracy tied.

This supports keeping original source files accessible to agents instead of relying only on long-context reading.

Do not overclaim

Do not say grep always beats full context.

Do not say tools solve all long-context tasks.

Do not say full context is useless. It uniquely solved 15 tasks here.

Do not mix this with compressed chat-memory results without saying they are different settings.

One-slide version

We ran the clean non-compacted control: 250 real long-context tasks, each twice: (1) source directly in the prompt, no tools; (2) same source saved as a file, Codex can search it. This produced 500 Codex runs, no synthetic tasks, no run failures, and 0 compaction events.

Result: file search was slightly better overall: 20% vs 16%. On BABILong exact-fact tasks it was clearly better: 17% vs 7%. On OOLONG-real aggregation tasks, exact accuracy tied at 22%.

Separate earlier result: in a 100-run long-agent-chat baseline, 68/100 runs did compact, with 240 total compaction events and 21% accuracy. That is the compressed-agent-memory setting, not the same as the 500-run clean control.

Verdict: search does not universally beat full context, but it can beat direct long-context reading on exact-fact retrieval. The practical takeaway is to keep original sources searchable for agents; do not rely only on the model remembering or reading a huge prompt.
